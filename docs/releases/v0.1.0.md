# Focus 0.1.0 — Make room for one thing

Focus is a quiet timer for desktop and Android by [Sugar](https://sugar.makersns.com), built with Tauri 2, Rust, React and TypeScript.

**Release-candidate notes.** The new interface and native integrations are still completing final acceptance. The older `f20…` installer generation is superseded and does not contain or validate this complete update. Publish the installer set below only after current-source CI, native acceptance and release verification pass.

## What is included

- Focus, short break and long break modes, with 25/5/15-minute defaults and custom 1–180-minute rounds.
- An integrated title area, a flat closed dial and a clear round action inside it. Digits count down while orange progress grows with time spent; pause freezes it and reset clears it.
- Ring, Tomato and Capsule desktop mini timers, with matching light/dark appearances, dragging, pinning and the same shared timer. Changing style does not restart your round. On macOS, pinned minis can remain visible over another application's full-screen Space.
- A live macOS menu-bar countdown and an anchored native control panel, including operation in a true full-screen Space.
- A real Android home-screen AppWidget with the same three style choices and native countdown, sharing the app's timer and start/pause/resume actions.
- Optional completion notifications with permission status, system-settings guidance and a test action. An optional system notification sound respects the operating system's sound and Do Not Disturb rules.
- Native background timing and precise Android completion alarms.
- Local history and daily totals that distinguish completed sessions from early-ended focus time.
- Paused desktop/reboot recovery and Android same-boot process recovery, with atomic saves and corrupt-file preservation.
- Light/dark/system themes and Simplified Chinese, Traditional Chinese, English, Japanese and Korean.
- Original app icon, keyboard controls, reduced-motion support and an uncluttered interface.

## Verification status

Local checks have passed 37 frontend tests with strict TypeScript and production build, 54 macOS Rust tests with warnings-denied Clippy, and 11 Android JVM tests with ARM64 release lint. Normal and isolated macOS QA builds passed with the corrected first-run permission guidance. Real macOS menu-popover checks passed full-screen placement, dismissal and opening the main window. All three Mini styles passed visibility above another app's full-screen Space, with native first-click actions, dragging, hide/reopen and unpin checks. Actual OS notification authorization and both sound-enabled/silent test requests also passed, with visible test notifications and unchanged paused timer/history/preferences. Earlier Android native notification QA passed 22 cases.

The macOS natural one-minute completion also passed: one completed record, a stable zero timer and a visible OS completion notification. The normal local macOS app upgrade preserved its existing user state, and its installed Mini passed the full-screen check. Required CI for the final source commit and final cross-platform distribution acceptance remain open. Notification sound settings and request flags were verified; physical audibility was not monitored. Mac full-screen checks used macOS 15.5 on one built-in display; mixed-DPI display behavior has geometry unit coverage but no actual multi-display observation. These notes do not count older installers or browser screenshots as passing native release evidence. See [verification scope and remaining gates](https://github.com/makersns/focus-timer/blob/v0.1.0/docs/VERIFICATION.md).

| Android 7+ · arm64 | Focus_0.1.0_android-arm64.apk |

The final `SHA256SUMS.txt` must contain every installer hash. The macOS app is ad-hoc signed but not Apple-notarized. Windows installers do not have a publisher certificate. OS trust prompts may appear; use this release's verified assets and hashes. Linux tray behavior depends on the desktop environment.

Desktop components are floating application windows; the macOS mini is not a WidgetKit system widget. Android uses an actual launcher AppWidget. Style changes are shared across widgets on the same device. Completion notifications start disabled, permission is not requested at launch, and the next round never starts automatically. Testing a notification does not change the timer or history; the system determines whether a requested notification is displayed or sounded.

Data stays local, with no account, cloud sync or automatic updater. Desktop runtime checkpoints are at most 30 seconds apart; a crash restores the saved remainder as paused. Android same-boot recovery uses boot/elapsed-time metadata and the original round identity; reboot recovery is paused. [Android behavior and signing](https://github.com/makersns/focus-timer/blob/v0.1.0/docs/ANDROID.md).

# Focus 0.1.0 · 留一点时间，只做好一件事

这是 [Sugar](https://sugar.makersns.com) 制作的独立桌面与 Android 专注应用首版，使用 Tauri 2、Rust、React 和 TypeScript 开发。

**候选版本说明。** 新界面与原生能力仍在完成最后验收。旧 `f20…` 安装包已被本轮更新取代，不能用于证明新版功能已经验证或发布。需要当前源码的 CI、原生实测及最终安装包检查全部通过后，再发布上表中的安装包。

## 这一版包含

- 专注、短休息、长休息，默认 25 / 5 / 15 分钟；支持 1–180 分钟自定义。
- 融合标题栏、平面闭合圆环，以及圆环内的圆形主操作。数字倒计时，橙色随已投入的时间增长；暂停时停住，重置后归零。
- 圆环、番茄、胶囊三款桌面悬浮计时，支持浅深外观、拖动和置顶，始终共享同一计时；切换样式不会重新开始本轮。macOS 置顶组件可继续显示在其他应用的全屏空间上方。
- macOS 菜单栏动态剩余时间与原生快捷面板，面板可在真实全屏空间中使用。
- 真正的 Android 主屏幕 AppWidget，提供相同的三款样式、原生倒计时，以及与应用同步的开始、暂停、继续操作。
- 按需开启的完成通知、权限状态、系统设置指引与测试提醒；提示音作为系统通知的可选项，遵循系统声音和勿扰设置。
- 原生后台计时与 Android 准确到期闹钟。
- 本机历史与每日汇总，区分完整完成和提前结束的专注时间。
- 桌面退出或设备重启后暂停恢复；Android 同次开机的进程回收后可恢复当前计时；原子写入并保留损坏数据。
- 浅色 / 深色 / 跟随系统，以及简体中文、繁體中文、English、日本語、한국어。
- 原创应用图标、键盘操作与减少动态效果支持。

## 验证进度

本地已通过 37 项前端测试、严格 TypeScript 与生产构建，54 项 macOS Rust 测试及拒绝警告的 Clippy，以及 11 项 Android JVM 测试和 ARM64 release lint。修正首次权限引导后的正常客户端与独立 macOS QA 应用均已构建通过。macOS 原生菜单面板已通过真实全屏定位、关闭交互和打开主窗口实测；三款 Mini 已通过在其他应用全屏空间上方显示，以及首次点击、原生拖动、隐藏重开和取消置顶检查。原生通知也已完成真实系统授权、有声与静音测试请求检查，实际显示了测试通知，暂停的计时、历史与偏好数据保持不变。此前 Android 原生通知专项已通过 22 项检查。

macOS 真实一分钟自然到期也已通过：只新增一条完成记录，计时稳定停在零，并实际显示系统完成通知。本机正常客户端升级前后用户数据一致，已安装的 Mini 也通过跨全屏检查。最终源码提交对应的完整 CI 和跨平台发布包验收仍待完成。声音已核对系统配置与请求参数，没有物理听音通道，因此不记为“实听通过”。Mac 全屏实测环境为 macOS 15.5 单内置屏；混合 DPI 显示器只有几何单元测试覆盖，尚无多屏实机记录。旧安装包、浏览器截图与局部构建结果不会代替这些检查。完整范围见[验收矩阵](https://github.com/makersns/focus-timer/blob/v0.1.0/docs/VERIFICATION.md)。

上方下载表列出的是计划发布的文件名。macOS 通用包同时包含 Apple Silicon 与 Intel 架构，Windows 和 Linux 为 x64，Android APK 适用于 Android 7 及以上的 ARM64 设备。最终每个安装包的校验值应收录于 `SHA256SUMS.txt`。

首版尚未进行 Apple 公证，也没有 Windows 发布者证书，系统可能显示开发者未识别提示。请使用最终发布页的安装包并核对校验值。Linux 托盘取决于桌面环境。

macOS / Windows 提供轻量应用悬浮窗口，macOS Mini 不是 WidgetKit 系统小组件；Android 提供真正的主屏幕 AppWidget。同一设备上的组件共用样式选择。完成通知默认关闭，不在启动时弹出权限请求；测试提醒不会改变计时或记录，系统决定通知是否显示或播放声音。下一轮由你主动开始。

无需账号，不提供云同步或自动更新。桌面运行中最长每 30 秒保存一次检查点，意外退出后以暂停状态恢复。Android 同次开机恢复会核对开机标识与经过时间；设备重启后暂停恢复。
