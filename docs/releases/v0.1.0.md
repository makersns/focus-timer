# Focus 0.1.0 — Make room for one thing

Focus is a quiet timer for desktop and Android by [Sugar](https://sugar.makersns.com), built with Tauri 2, Rust, React, and TypeScript.

## What is included

- Focus, short break, and long break modes, with 25/5/15-minute defaults and custom 1–180-minute rounds.
- A seamless single-column interface matching the approved design, with warm light and dark appearances.
- A live macOS menu-bar countdown, a compact control panel, and a draggable/pinnable desktop mini timer.
- A native Android home-screen AppWidget that shares the app's timer, with start/pause/resume controls.
- Native background timing, precise Android completion alarms, and optional completion notifications.
- Local session history and daily totals, with completed and early-ended focus counted honestly.
- Paused desktop/reboot recovery and Android same-boot process recovery, with atomic saves and corrupt-file preservation.
- Light/dark/system themes and Simplified Chinese, Traditional Chinese, English, Japanese, and Korean.
- Original app icon, keyboard controls, reduced-motion support, and an uncluttered interface.

SHA256SUMS.txt contains the hash of every installer. The macOS app is ad-hoc signed but not Apple-notarized. Windows installers do not have a publisher certificate. OS trust prompts may appear; use the assets from this release and check their hashes. Linux tray behavior depends on the desktop environment.

Desktop components are floating mini windows; Android uses an actual launcher AppWidget. Completion notifications are optional, and the next round never starts automatically. No account or cloud connection is needed. Desktop runtime checkpoints are at most 30 seconds apart; after a crash, the saved remainder is restored as paused. Android same-boot recovery uses boot/elapsed-time metadata and the original round identity; reboot recovery is paused. [Android behavior and signing](../ANDROID.md).

# Focus 0.1.0 · 留一点时间，只做好一件事

这是 [Sugar](https://sugar.makersns.com) 制作的独立桌面与 Android 专注应用首版，使用 Tauri 2、Rust、React 和 TypeScript 开发。

## 这一版包含

- 专注、短休息、长休息，默认 25 / 5 / 15 分钟；支持 1–180 分钟自定义。
- 按已确认设计实现的单列主界面、融合顶栏及暖色浅深外观。
- macOS 菜单栏实时剩余时间、快捷控制面板和可拖动、可置顶的桌面悬浮小组件。
- 真正的 Android 主屏幕 AppWidget，与应用共用计时，并支持开始、暂停、继续。
- 原生后台计时、Android 准确到期闹钟，以及按需开启的完成通知。
- 保存在本机的历史与每日汇总，区分完整完成和提前结束的专注时间。
- 桌面退出或设备重启后暂停恢复；Android 同次开机的进程回收后可恢复当前计时；原子写入并保留损坏数据。
- 浅色 / 深色 / 跟随系统，以及简体中文、繁體中文、English、日本語、한국어。
- 原创应用图标、键盘操作、减少动态效果支持与简洁的主界面。

下载请按上表选择系统。macOS 通用包同时包含 Apple Silicon 与 Intel 架构，Windows 和 Linux 为 x64，Android APK 适用于 Android 7 及以上的 ARM64 设备。每个安装包的校验值均在 SHA256SUMS.txt 中。

首版尚未进行 Apple 公证，也没有 Windows 发布者证书，系统可能显示开发者未识别提示。请从本发布页下载并核对校验值。Linux 托盘取决于桌面环境。

macOS / Windows 提供轻量悬浮窗口，Android 提供系统主屏幕组件。无需账号，不提供云同步或自动更新；完成通知可选，下一轮不会自动开始。桌面运行中最长每 30 秒保存一次检查点，意外退出后以暂停状态恢复。Android 同次开机恢复会核对开机标识与经过时间；设备重启后暂停恢复。
