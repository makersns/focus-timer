# Focus 0.1.0 — Make room for one thing

A calm, local-first focus timer for macOS, Windows, Linux and Android, made by [Sugar](https://sugar.makersns.com).

[Source](https://github.com/makersns/focus-timer/tree/v0.1.0) · [Project](https://sugar.makersns.com/projects/focus) · [Report an issue](https://github.com/makersns/focus-timer/issues)

## One timer, wherever you need it

- **Focus and take a real break.** Focus, short-break and long-break modes start with 25/5/15-minute defaults. Choose any duration from 1 to 180 minutes. The next round starts when you choose.
- **A clear, quiet interface.** A flat, complete dial keeps the countdown readable. Orange progress grows with time spent, freezes when paused and clears on reset.
- **Three desktop mini timers.** Ring, Tomato and Capsule share the same native timer. Drag, pin, hide or change their appearance without restarting your round. On macOS, a pinned mini can stay above another application's full-screen Space without bringing the main window forward.
- **A live macOS menu-bar timer.** Remaining time and an elapsed-progress icon stay close at hand. An anchored native panel provides quick actions, including in a full-screen Space.
- **A real Android home-screen widget.** The launcher AppWidget offers the same three style choices, a native countdown and shared start, pause and resume controls.
- **Reminders you control.** Completion notifications start disabled. Settings shows the system's permission state, offers an explicit test and provides system-settings guidance. Sound is part of the single system notification and remains subject to OS mute, volume, channel and Do Not Disturb settings.
- **Local history and recovery.** Daily totals distinguish completed sessions from early-ended focus time. State saves are atomic, damaged files are preserved, desktop recovery is paused, and Android can recover a running round after process removal during the same device boot.
- **Five languages and three themes.** English, 简体中文, 繁體中文, 日本語 and 한국어; light, dark or system appearance. Keyboard controls and reduced-motion support are included.

There is no account requirement, cloud sync or automatic updater. Desktop mini timers are floating app windows; the macOS mini is not a WidgetKit widget. Android uses an actual launcher AppWidget.

## Validation and practical limits

Release source: [6ace789bfe63db7dde3449236d7cdde9ca591d0c](https://github.com/makersns/focus-timer/commit/6ace789bfe63db7dde3449236d7cdde9ca591d0c). The [main CI](https://github.com/makersns/focus-timer/actions/runs/45241402661) passed all five platform jobs. Windows and Linux installers are built by the [verified-source packaging workflow](https://github.com/makersns/focus-timer/actions/runs/45247245331), which checks the unchanged tag and all five passing source checks before packaging. The macOS universal DMG and release-signed Android APK are built locally from the same clean tagged source. Platform manifests and the verification record preserve these distinct origins.

- **Frontend:** 37 tests, strict TypeScript and production build.
- **macOS:** 54 Rust tests and Clippy; actual menu-bar and all three mini-style checks above another application's true full-screen Space; first-click actions, dragging, hiding, recovery, real notification authorization and a natural one-minute completion.
- **Windows:** 52 Rust tests with no ignored or filtered tests, including the real WinRT lifetime regression; Clippy; seven actual Tauri/WebView2 window scenarios; 110 OS foreground/z-order observations. Five native screenshots were visually reviewed.
- **Linux:** native tests, Clippy and package builds on Ubuntu 22.04.
- **Android:** 11 local JVM tests, release lint without errors, release-signature and 16 KiB alignment checks, plus installation and runtime acceptance of the actual signed APK.

The detailed [verification record](https://github.com/makersns/focus-timer/blob/main/docs/VERIFICATION.md) identifies the builds, evidence and exact scope. macOS GUI checks used Apple Silicon, macOS 15.5 and one built-in display; mixed-DPI multi-display behavior has geometry tests but no physical multi-display observation. Windows acceptance covers real application windows and WinRT objects, not a separately observed Windows toast. Linux desktop GUI variations were not exercised. Android runtime checks used a dedicated ARM64 API 36 emulator with 16 KiB pages, not a physical handset or every supported OS version. Notification sound settings and request flags were checked; physical audibility was not monitored.

# Focus 0.1.0 · 留一点时间，只做好一件事

这是 [Sugar](https://sugar.makersns.com) 制作的独立专注应用，支持 macOS、Windows、Linux 和 Android，计时与记录保存在本机。

## 同一份计时，放在顺手的位置

- **专注、短休息、长休息。** 默认 25 / 5 / 15 分钟，可自定义 1–180 分钟；下一轮由你主动开始。
- **清楚、安静的主界面。** 平面闭合圆环突出剩余时间；橙色随已投入时间增长，暂停时停住，重置后归零。
- **圆环、番茄、胶囊三款桌面悬浮计时。** 支持拖动、置顶、隐藏及浅深主题，切换样式不会重新开始本轮。macOS 置顶小窗可显示在其他应用真正的全屏空间上方，并保持主窗口不被带到前台。
- **macOS 菜单栏常驻计时。** 显示剩余时间和动态进度；原生快捷面板紧贴菜单栏图标，也能在全屏空间使用。
- **真正的 Android 主屏幕小组件。** 使用系统 AppWidget，提供同样的三款样式、原生倒计时，以及与应用同步的开始、暂停和继续操作。
- **按需开启的完成提醒。** 通知默认关闭；设置页展示系统权限状态，提供明确的测试入口和系统设置指引。声音属于同一条系统通知，遵循系统静音、音量、通知渠道和勿扰设置。
- **本机历史与恢复。** 每日汇总区分完整完成与提前结束；原子保存并保留损坏数据。桌面恢复时保持暂停；Android 在同次开机的进程回收后可继续恢复当前一轮。
- **五种语言、三种主题。** 简体中文、繁體中文、English、日本語、한국어；浅色、深色或跟随系统，附带键盘操作与减少动态效果支持。

无需账号，没有云同步或自动更新。桌面小组件是轻量应用悬浮窗口，macOS Mini 不是 WidgetKit 系统组件；Android 提供真正的主屏幕 AppWidget。

## 安装与校验

上方下载表提供六个安装包：macOS 通用 DMG 包含 Apple Silicon 与 Intel 架构，Windows 和 Linux 为 x64，Android APK 适用于 Android 7 及以上的 ARM64 设备。请用发布页的 `SHA256SUMS.txt` 核对文件；各平台 manifest 记录对应源码提交、架构、大小和校验值。

macOS 应用采用临时签名，**尚未进行 Apple 公证**；Windows 安装包**没有发布者签名证书**，系统可能提示开发者未识别。Android 使用项目专属发布密钥签名，不分发 debug APK。Linux 托盘行为取决于桌面环境。

## 实际验证范围

发布源码固定为 [6ace789b](https://github.com/makersns/focus-timer/commit/6ace789bfe63db7dde3449236d7cdde9ca591d0c)，[五平台 main CI](https://github.com/makersns/focus-timer/actions/runs/45241402661) 已全部通过。

Windows/Linux 由[同源码打包流水线](https://github.com/makersns/focus-timer/actions/runs/45247245331)生成，打包前再次核验固定标签与五个平台检查结果；macOS 通用 DMG 和发布签名 Android APK 在本机从同一份干净源码构建。各平台 manifest 与验收记录明确保留这些产物来源。

- 前端通过 **37 项测试**、严格类型检查和生产构建。
- macOS 通过 **54 项 Rust 测试**及 Clippy，并实际检查菜单栏面板、三款悬浮组件跨全屏显示、首次点击、拖动、隐藏、状态保留、系统通知授权和真实一分钟自然到期。
- Windows 通过 **52 项 Rust 测试**，没有忽略或过滤项，包含真实 WinRT 生命周期回归；Clippy 和 **7 项真实原生窗口场景**通过，置顶与取消置顶共进行了 **110 次操作系统焦点及层级观测**，并逐张查看了五张原生截图。
- Linux 通过 Ubuntu 22.04 上的原生测试、Clippy 和打包。
- Android 通过 **11 项本地 JVM 测试**及无错误的 release lint；实际发布签名 APK 完成安装与运行验收，并核对签名和 16 KiB 对齐。

完整证据与适用范围见[验收记录](https://github.com/makersns/focus-timer/blob/main/docs/VERIFICATION.md)。Mac GUI 实测使用 macOS 15.5、Apple Silicon 和单内置屏；多屏与混合 DPI 仅有几何测试。Windows 未单独实测系统 Toast 的可见投递；Linux 未实测不同桌面环境的 GUI。Android 使用 API 36 ARM64 专用模拟器，没有将结果扩大为所有实体设备和系统版本均已测试。通知声音已核对系统设置与请求参数，没有物理听音通道，因此不声称“实听通过”。
